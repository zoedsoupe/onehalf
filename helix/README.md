# Helix

[Helix]() is self defined post modern modal editor, cross-platform, built in rust and with the idea of minimum configuration needed to start using as an complete code editor.

Helix config files for themes are placed on `$XDG_CONFIG_HOME/helix/themes` where the themes files are TOML format files.

Simply copy any of the variants you want from this repo, open helix editor and issue the `:theme` command, then search for "onehalf" and there's you go.
